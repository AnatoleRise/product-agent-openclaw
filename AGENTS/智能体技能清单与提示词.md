# 智能体技能清单与提示词

> 本文件梳理 6 个子智能体各自依赖的 Skill，并为每个智能体提炼一句可直接用于其他渠道的系统提示词。Skill 元数据来源于仓库 `skills/*/SKILL.md`，归属关系综合自各智能体 `AGENTS.md` 显式声明与 `README.md` 6.2 节配套说明。

---

## 一、技能清单总览

| 智能体 | 核心 Skill | 配套/相关 Skill | 通用 Skill |
|:---|:---|:---|:---|
| 客研管理智能体 | `customer-research` | — | `telemetry-tracker` |
| 产品探索智能体 | `product-exploration`、`competitor-web-crawler`、`report-generator`、`difference-panel` | `competitor-research`、`search-engine`（备选/通用搜索链路） | `telemetry-tracker` |
| 需求评审智能体 | `requirement-review` | `logic-detector`、`issue-tracker` | `telemetry-tracker` |
| 需求管理智能体 | `feishu-requirement-entry`、`feishu-requirement-board`、`feishu-requirement-archive` | `pm-weekly-monitor`（相关，待确认） | `telemetry-tracker` |
| 产品需求方案智能体 | `prd-document-generator`、`business-diagram-generator`、`interactive-prototype-generator` | — | `telemetry-tracker` |
| 用户分析智能体 | `app-market-sentiment`、`core-metrics-analysis`、`user-feedback-processor`、`data-visualization`、`alert-early-warning` | — | `telemetry-tracker` |

> ⚠️ `telemetry-tracker` 为 OpenClaw 平台埋点技能，换到其他渠道时各智能体均可移除。

---

## 二、各智能体技能详情与提示词

### 1. 客研管理智能体（`customer_research`）

**依赖 Skill**

| Skill | 路径 | 用途 |
|:---|:---|:---|
| `customer-research` | `skills/customer-research/` | 从访谈记录中提炼痛点，生成结构化访谈报告、候选需求条目与待澄清问题列表 |
| `telemetry-tracker` | `skills/telemetry-tracker/` | 能力调用埋点上报（OpenClaw 专有） |

**一句话提示词**

> 你是客研管理智能体，负责将访谈记录、会议纪要与录音转写结构化为痛点清单、候选需求与待澄清问题，所有结论必须可回溯到原文，不做竞品对标与 PRD 产出。

---

### 2. 产品探索智能体（`product_discovery`）

**依赖 Skill**

| Skill | 路径 | 用途 |
|:---|:---|:---|
| `product-exploration` | `skills/product-exploration/` | workflow 主技能，意图判断 + 编排抓取/报告/差异面板 |
| `competitor-web-crawler` | `skills/competitor-web-crawler/` | 自动发现并抓取竞品网页，返回去重后的结构化证据 |
| `report-generator` | `skills/report-generator/` | 对抓取证据做结构化清洗，按模板生成竞品分析报告 |
| `difference-panel` | `skills/difference-panel/` | 将竞品数据转为维度化差异面板，标注领先/持平/缺失/未知 |
| `competitor-research` | `skills/competitor-research/` | 备选：另一套竞品调研编排主技能（与 product-exploration 功能重叠） |
| `search-engine` | `skills/search-engine/` | 备选：competitor-research 的搜索策略子技能 |
| `telemetry-tracker` | `skills/telemetry-tracker/` | 能力调用埋点上报（OpenClaw 专有） |

**一句话提示词**

> 你是产品探索智能体，通过自动抓取竞品网页、清洗证据、生成结构化分析报告与差异面板，帮助产品经理从信息搜集中解放出来专注判断，每个结论必须可追溯到来源 URL，绝不编造未找到的信息。

---

### 3. 需求评审智能体（`requirement_review`）

**依赖 Skill**

| Skill | 路径 | 用途 |
|:---|:---|:---|
| `requirement-review` | `skills/requirement-review/` | PRD 评审主技能，多角色全方位审查与结构化评审纪要 |
| `logic-detector` | `skills/logic-detector/` | 形式化逻辑验证：状态机完整性、跨章节矛盾、数据流一致性、时序依赖 |
| `issue-tracker` | `skills/issue-tracker/` | 问题工单化、PRD 版本 Diff、修复效果复检、整改统计与趋势 |
| `telemetry-tracker` | `skills/telemetry-tracker/` | 能力调用埋点上报（OpenClaw 专有） |

**一句话提示词**

> 你是需求评审智能体，从多角色视角发现会阻塞研发、测试、上线与验收的需求缺陷，按严重度输出可执行的整改建议，结论必须可追溯到 PRD 原文，不替代业务 Owner 拍板也不改写最终定稿。

---

### 4. 需求管理智能体（`requirement_management`）

**依赖 Skill**

| Skill | 路径 | 用途 |
|:---|:---|:---|
| `feishu-requirement-entry` | `skills/feishu-requirement-entry/` | 需求信息标准化录入飞书多维表格，智能评估并生成 ID |
| `feishu-requirement-board` | `skills/feishu-requirement-board/` | 从飞书表格读取数据生成可视化看板 HTML |
| `feishu-requirement-archive` | `skills/feishu-requirement-archive/` | 扫描已上线/已转出需求，生成归档统计报告 |
| `pm-weekly-monitor` | `skills/pm-weekly-monitor/` | 相关：项目周报监控与风险预警（归属待确认） |
| `telemetry-tracker` | `skills/telemetry-tracker/` | 能力调用埋点上报（OpenClaw 专有） |

**一句话提示词**

> 你是需求管理智能体，依托飞书多维表格数据底座，负责需求归类查重、价值初评、进度巡检、风险预警、看板生成与归档统计，确保没有任何需求在无人关注的情况下卡住。

---

### 5. 产品需求方案智能体（`solution_design`）

**依赖 Skill**

| Skill | 路径 | 用途 |
|:---|:---|:---|
| `prd-document-generator` | `skills/prd-document-generator/` | 基于模板与需求输入，生成标准化 PRD 文档（PDF/DOCX） |
| `business-diagram-generator` | `skills/business-diagram-generator/` | 自动绘制泳道图、流程图、时序图 |
| `interactive-prototype-generator` | `skills/interactive-prototype-generator/` | 生成单 HTML 多页面可交互 UI 原型 |
| `telemetry-tracker` | `skills/telemetry-tracker/` | 能力调用埋点上报（OpenClaw 专有） |

**一句话提示词**

> 你是产品需求方案智能体，收到需求后立即生成标准化 PRD 文档、业务流程图/时序图与可交互 UI 原型三件套，输入不足时使用默认值并标注缺口，不询问、不引导、直接交付。

---

### 6. 用户分析智能体（`user_analysis`）

**依赖 Skill**

| Skill | 路径 | 用途 |
|:---|:---|:---|
| `app-market-sentiment` | `skills/app-market-sentiment/` | 应用商店评论采集、语义分析、痛点挖掘、版本趋势对比 |
| `core-metrics-analysis` | `skills/core-metrics-analysis/` | 规模与价值指标交叉分析、量价背离诊断、异常检测 |
| `user-feedback-processor` | `skills/user-feedback-processor/` | 多渠道反馈清洗、去重、归类、需求提取 |
| `data-visualization` | `skills/data-visualization/` | 转化为可交互 HTML 看板（趋势图/饼图/热力图/词云） |
| `alert-early-warning` | `skills/alert-early-warning/` | 舆情爆发与指标异常实时预警，多渠道通知 |
| `telemetry-tracker` | `skills/telemetry-tracker/` | 能力调用埋点上报（OpenClaw 专有） |

**一句话提示词**

> 你是用户分析智能体，整合应用市场舆情、核心业务指标与多渠道用户反馈，用定性定量互证定位痛点、诊断异常并主动预警，为需求决策提供数据支撑，不做优先级裁定与排期承诺。
